# Project Reviewer Config — GW-BASIC C Port

## Build
- Command: `mingw32-make clean && mingw32-make test`
- Pass threshold: 1080+ tests passing
- Test failures = CRITICAL

## Conventions

| Rule | Description |
|------|-------------|
| Pointer to int | Use `intptr_t`, never `(int)` cast |
| String compare | POSIX-free, use project's own ASCII compare, not `strcasecmp` |
| Debug output | Use `DEBUG_PRINT` macro, controlled by `-DDEBUG` |
| Structs | Define in `gwbasic.h`, never redeclare in `.c` |
| Layout | `src/`, `include/`, `tests/` |
| Platform | Windows / MinGW64 |
| `test_runner.c` | Never use `patch replace_all` — corrupts the file |

## Known Pitfalls

- **Pixel bitmask**: advance by checking **low** bits (`mask & 0x01` / `mask & 0x03`), not high bits (`0x80`/`0xC0` — causes infinite loop within one byte)
- **GET/PUT pixel packing**: MSB-first — pixel at mask position stays at mask position
- **`gengrp.c` framebuffer stride**: must use `MAX_WIDTH` (640), not `g_fb_width`
- **`gengrp_point`**: must never call `scan_coord`
- **FOR/NEXT**: FOR matches by variable name, NEXT finds matching FOR entry, uses text pointer jumps

## Severity Definitions

| Severity | Tag | Meaning |
|----------|-----|---------|
| CRITICAL | 🟥 | Blocks merge: memory safety, crashes, data corruption, incorrect GW-BASIC behavior |
| HIGH | 🟧 | Missing/broken core functionality, missing tests for implemented feature, function not registered in `test_runner.c` or declared in `gwbasic.h` |
| MEDIUM | 🟨 | Edge cases, incomplete vs ASM, test gaps, style inconsistency |
| LOW | 🟩 | Compiler warnings, unused variables, cleanup, formatting |
